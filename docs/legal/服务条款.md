## 一、服务内容

1.1 本服务（以下简称「服务」）提供跨境选品的利润测算、评分排序、日报生成与风险预警功能。
1.2 服务可能包含第三方大模型生成内容、第三方数据源信号与用户自行导入的数据；相关结果仅供参考，不构成投资、经营或法律建议。
1.3 运营方有权根据业务需要调整功能、套餐与价格，重大变更将提前在站内公告。

## 二、账号与安全

2.1 用户应提供真实、有效的邮箱信息，并妥善保管账号密码与 API Key。
2.2 账号仅限订阅主体内部使用，不得转售、出租或共享给第三方。
2.3 发现账号被非授权使用时，应立即通知运营方并修改密码；运营方有权暂停异常账号。

## 三、使用规范

用户承诺不得利用本服务：
- 采集、存储、分析侵犯他人知识产权或违反目标平台条款的数据；
- 发布违法商品信息、虚假宣传、医疗功效承诺或其他违反广告法的内容；
- 对服务进行反向工程、压力测试、绕过配额或安全限制；
- 上传恶意代码、病毒或含有攻击性的内容。

## 四、数据与知识产权

4.1 用户导入的商品、成本、销售等数据归用户所有；运营方仅为提供服务进行处理。
4.2 服务的软件、界面、评分方法与文档归运营方所有，未经许可不得复制、分发或用于竞品开发。
4.3 用户授予运营方为提供服务所必需的、有限的、可撤回的数据处理许可。

## 五、付费、配额与退款

5.1 套餐价格、配额与计费周期以购买页面为准。
5.2 因用户原因导致的超额使用、账号停用或数据删除，已支付费用不予退还，法律另有规定的除外。
5.3 运营方调整价格应提前 30 日通知；用户不同意可在生效前终止订阅。

6.2 因不可抗力、网络故障、第三方服务中断导致的服务暂停，运营方将尽力恢复但不承担间接损失。

## 七、服务终止

7.1 用户可随时停止使用并申请删除数据；删除后不可恢复。
7.2 用户严重违反本条款的，运营方有权立即终止服务且不退还费用。
